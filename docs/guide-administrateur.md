# Guide administrateur – Site CIOFF France

Pour les **Administrateurs CIOFF**. Aucune connaissance technique n'est nécessaire.

Connexion : `cioff-france.org/wp-admin`

---

## 1. Le tableau de bord

L'encadré **CIOFF France** indique le nombre d'éléments à valider et donne accès aux actions courantes.
Le menu **À valider** (en haut à gauche) affiche une pastille rouge quand un adhérent a envoyé quelque chose.

## 2. Valider les contenus des adhérents

**Menu « À valider »**. Trois rubriques s'y trouvent :

| Rubrique | Contenu |
|---|---|
| Nouvelles fiches | Fiche envoyée pour la première fois par un adhérent. |
| Modifications de fiches publiées | Tableau « version en ligne / modification proposée ». La version actuelle reste en ligne en attendant. |
| Événements proposés | Événements soumis pour l'agenda. |

Pour chaque élément :
- **✔ Valider et publier** : c'est en ligne tout de suite (et sur la carte), et l'adhérent reçoit un e-mail.
- **↩ Renvoyer pour correction** : écrivez d'abord un commentaire. L'adhérent le reçoit par e-mail et le retrouve dans « Mon espace ».

Vous pouvez aussi corriger vous-même une fiche avant de la publier (lien « Voir et modifier la fiche complète »).

## 3. Gérer les comptes adhérents

**Comptes → Ajouter**
1. Renseignez l'identifiant et l'e-mail.
2. Choisissez le **rôle** : il détermine le type de fiche de l'adhérent.

| Rôle | Type de fiche |
|---|---|
| Responsable festival | Festival |
| Responsable festival associé | Festival associé |
| Responsable groupe labellisé | Groupe labellisé |
| Responsable groupe associé | Groupe associé |
| Membre participant | Membre participant |
| Membre individuel | Membre individuel (fiche simplifiée) |
| Administrateur CIOFF | Accès complet, validation |

3. Cochez « Envoyer une notification » : l'adhérent reçoit un lien pour choisir son mot de passe.

## 4. L'annuaire

**Menu « Annuaire »** : liste de toutes les fiches, avec un filtre par type. La colonne **Carte** indique ✅ si la fiche est placée sur la carte et ⚠️ si la ville n'a pas été trouvée.

Pour créer ou modifier une fiche vous-même :
- **Titre** = nom de la structure. **Texte** = présentation. **Image mise en avant** = photo principale.
- Boîte **Informations de la fiche** : choisissez d'abord le **type**, puis seuls les champs utiles s'affichent.
- **Auteur** (panneau de droite) : le compte adhérent responsable de la fiche.
- **Position sur la carte** : automatique. Pour la corriger, cochez « Position saisie à la main » et entrez latitude et longitude.

## 5. L'agenda

**Menu « Agenda » → Ajouter un événement**
- Titre, description, date de début (et de fin si l'événement dure plusieurs jours), heure, lieu, lien.
- **Catégorie** (panneau de droite) : *Réunion CIOFF France* et *Réunion CIOFF Jeunes* apparaissent dans les encadrés « Prochaines réunions » de l'accueil.
- Cochez **« À la une »** pour l'afficher en haut de la page d'accueil.
- Les événements passés disparaissent tout seuls des listes.

## 6. Modifier les pages

**Pages** : cliquez sur une page, puis modifiez le texte directement, comme dans un traitement de texte.
- Ajouter un élément : bouton **+**. La catégorie **CIOFF France** contient les blocs du site (carte, agenda, thème annuel, formulaires…).
- Ajouter un document à télécharger (Boîte à outils, intranet) : glissez-déposez le fichier PDF dans la page (bloc « Fichier »).
- Les paragraphes surlignés en jaune **[À compléter]** sont des textes provisoires à remplacer.
- Cliquez sur **Mettre à jour** pour enregistrer.

## 7. L'intranet

- La page **Intranet** et **toutes ses sous-pages** sont réservées aux adhérents connectés. Pour ajouter une page à l'intranet, créez-la avec « Intranet » comme page parente (panneau de droite → Page parente).
- Toute autre page peut être réservée dans l'encadré **Accès (intranet)** du panneau de droite.
- Pour réserver une page à certains profils seulement (ex. uniquement les festivals), cochez-les dans ce même encadré.
- ⚠ Un fichier PDF déposé dans une page réservée reste accessible à quiconque connaît son adresse exacte. N'y mettez pas de document très sensible.

## 8. Réglages CIOFF

**Menu « Réglages CIOFF »** :
- **Thème annuel** : titre, texte et image affichés sur l'accueil.
- **Liens** : adresse du CIOFF International, Facebook, Instagram, YouTube (icônes du pied de page).
- **E-mails prévenus** : qui reçoit les notifications « à valider ».
- **Formulaire de contact** : les catégories de la liste déroulante et, pour chacune, les adresses qui reçoivent le message. Plusieurs adresses sont possibles, séparées par des virgules. On peut ajouter, renommer ou supprimer des catégories.

**Menu « Messages »** : archive de tous les messages envoyés par le formulaire de contact.

## 9. Apparence (menu, couleurs, logo)

**Apparence → Éditeur**
- **Navigation** : ajouter, retirer ou réordonner les liens du menu.
- **Styles** : changer les couleurs et les polices de tout le site.
- **Modèles → En-tête / Pied de page** : logo, textes du pied de page.
- Logo : cliquez sur le logo dans l'en-tête, puis sur « Remplacer ».
